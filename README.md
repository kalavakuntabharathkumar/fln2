# Failure-Lens — LLM Eval Failure-Analysis Dashboard

TypeScript/Node evaluation-analysis service with 14 failure categories, deterministic LLM-as-judge fallback, optional Claude API judging, Redis-ready caching, Vitest and Playwright scaffolds.

Run: `npm install && npm run dev`
Test: `npm test`
API: `http://localhost:3000/api/runs`

The supplied resume metrics are project specification claims, not fabricated local benchmark results.
